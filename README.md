IRONLINE — a 5v5 round-based tactical FPS in three.js. Amber attacks, Cobalt defends: plant the charge at Foundry or the Yard, or wipe the enemy team. First to 8 rounds takes the match (max 15). Money between rounds buys rifles, SMGs, a sniper, a shotgun, Kevlar and smoke grenades; accuracy beats spray. Single-player against 9 bots with real routes, holds, rotations and plant/defuse behavior, on an original multi-lane map with procedural textures, dusk lighting and synthesized WebAudio sound. No build step, no network — static files only.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: WASD move, mouse look, click fire, R reload, Shift walk silently, Space jump, Ctrl crouch, 1/2/3 weapons, G smoke grenade, E plant/defuse, B buy menu, Tab scoreboard, H help, Esc pause.
